# 🧠 Quiziffy
A simple, interactive quiz app built with vanilla **HTML5, CSS3, and JavaScript** —
demonstrating core JavaScript logic, DOM manipulation and event handling.

## ✨ Features
- ❓ Multiple-choice questions shown one at a time
- ✅ Instant feedback on each answer
- 🏆 Score tracking throughout the quiz
- 📱 Responsive design — works on mobile and desktop

## 🛠️ Tech Stack
- **HTML5** — structure and layout
- **CSS3** — styling and responsive design
- **JavaScript** — quiz logic, score tracking, and DOM manipulation

## 🚀 Getting Started
1. Clone the repository
```bash
   git clone https://github.com/aqsaishtiaq19/Quiziffy.git
```
2. Open `index.html` in your browser — no dependencies required.
