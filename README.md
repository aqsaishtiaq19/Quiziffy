# 🧠 Quiziffy

A simple, interactive quiz app built with vanilla **HTML5, CSS3, and JavaScript** to practice core JavaScript logic, DOM manipulation, and event handling.

## ✨ Features
- ❓ Multiple-choice questions shown one at a time
- ✅ Instant feedback on each answer
- 🏆 Score tracking throughout the quiz
- 📱 Responsive design for mobile and desktop

## 🛠️ Tech Stack
- **HTML5** for structure
- **CSS3** for styling and responsive layout
- **JavaScript** for quiz logic, score tracking, and DOM manipulation

## 🚀 Getting Started
1. Clone the repository
```bash
   git clone https://github.com/aqsaishtiaq19/Quiziffy.git
   cd Quiziffy
```
2. Open `index.html` in your browser. No dependencies are required.

## 📚 What I Learned
- Handling click events and updating the page with the DOM
- Tracking state (current question and score) in JavaScript
- Deploying a static site with Netlify
